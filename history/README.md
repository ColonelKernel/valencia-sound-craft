# history/

Iteration-by-iteration notes the Ralph loop leaves for its future self.

One file per spec, named `<spec-slug>.md`. Ralph appends to it after each
attempt — what worked, what didn't, what to try differently next time.
When Ralph reopens a spec, it reads this file first.

This directory holds **learning notes, not logs.** For raw CLI output see
`logs/` (which is gitignored).
